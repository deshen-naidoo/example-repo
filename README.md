# example-repo

## Description
This project is a simple Python script designed to demonstrate 
the basics of Git version control, including commits and 
repository hosting on GitHub.

## Table of Contents
1. [Installation](#installation)
2. [Usage](#usage)

## Installation
Ensure you have Python installed. You can clone this repository 
using:
`git clone https://github.com/deshen-naidoo/example-repo.git`

## Usage
Navigate to the directory and run the following command:
`python hello_world.py`
